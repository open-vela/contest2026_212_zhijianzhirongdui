## 一、技术栈决策

| 层 | 选型 | 理由 |
|------|------|------|
| MQTT Broker | mosquitto (已有, 192.168.31.194:1883) | 零部署，够用 |
| API 框架 | FastAPI + Uvicorn | 原生 async/WebSocket/Swagger |
| 数据库 | SQLite (aiosqlite) | 零部署，论文写 PostgreSQL-ready |
| 前端框架 | Vue 3 + TypeScript | 生态成熟，NaiveUI+Tailwind |
| 管理端 UI | Naive UI | 暗色原生，科技感，tree-shaking |
| 员工端样式 | Tailwind CSS 4 手写玻璃 | iOS26 + HyperOS3 双主题 |
| 实时图表 | ECharts 5 | 热力图/折线图 |
| 认证 | JWT | 无状态，适合 API |
| 权限 | RBAC (角色) + ABAC (属性) 双层 | 基础+灵活，可平滑升级 |
| 部署 | 裸跑 | 比赛期不折腾 Docker |

## 五、员工端（6 页面 × 2 主题）

### 主题体系
- **iOS26 Glass**: 冷白色调、强模糊(24px)、SF Pro字体、标准圆角(20px)、线性动画、深投影
- **HyperOS3**: 暖灰色调、中模糊(18px)、MiSans字体、连续曲线圆角(28-32px)、Spring弹性动画、浅投影+发光边框
- **暗亮自动**: Geolocation获取位置 → 计算当日日落时间 → 日落后30min切换暗色 → 日出切回
- **用户手动覆盖**

### 页面

| 页面 | 功能要点 |
|------|------|
| 🏠 首页 | 通行摘要、空气质量卡片(PM2.5/CO₂/Temp/Hum)、会议提醒、通知中心、午休开关 |
| 🔐 身份与通行 | 通行记录时间线、人脸/BLE信息、隐私设置(区域开关/留存天数)、数据访问日志、暂停识别 |

## 六、权限模型

```
RBAC 基础层:
  admin ── 全部权限
  hr ──── 人员管理 + 访客审批
  it ──── 设备管理 + 固件更新
  security ── 安全审计 + 规则查看
  reception ── 访客登记 + 通行记录查看
  employee ── 仪表板 + 个人通行记录 + 员工端

ABAC 增强层:
  属性: {role, time, zone, resource, workplace_id}
  示例: employee + 08:00-20:00 + entrance + door → ALLOW
        visitor + 14:00-15:00 + !sensitive_zone + door → ALLOW
        employee + 22:00-06:00 + server_room → DENY + ALERT

多租户:
  workplace_id 隔离数据
```
